# Juego Lanza y Atrapa

Juego interactivo desarrollado en JavaScript, HTML5 Canvas y CSS3 con sistema de audio integrado y panel de evaluación.

## Archivos del proyecto
- `index.html`: Estructura principal y canvas del juego.
- `style.css`: Estilos visuales, animaciones y diseño responsivo.
- `game.js`: Lógica principal del juego (físicas, mecánicas de lanzamiento y captura, puntuación).
- `audio.js`: Sistema de efectos de sonido y síntesis de audio Web Audio API.
- `evaluation.js`: Módulo de evaluación de rendimiento y métricas.
- `prototipo_original.jpg`: Imagen de referencia del diseño conceptual original.
